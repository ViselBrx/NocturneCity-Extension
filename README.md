# Nocturne City

**Ten city nights. One VS Code theme collection.** Nocturne City brings together dark color themes inspired by neon skylines, rain-soaked streets, old town alleys, amber streetlights, harbor lights and moonlit avenues. Each theme carries its atmosphere through the editor, syntax and terminal.

Choose from seven city moods: **Nocturne City, Midnight Skyline, Neon District, Rainy Avenue, Sodium Street, Midnight Harbor** and **After Hours**. Three old town themes add **Gothic Lantern** for amber-lit alleys, **Verdant Fog** for green mist and **Moonlit Gothic** for moonlit towers and warm windows.

## Try it

To build the extension locally, use Node.js 22 or later:

```sh
npm ci
npm run package
code --install-extension nocturne-city-theme-0.3.0.vsix
```

Then open **Preferences: Color Theme** in VS Code and choose a Nocturne City theme.
